## Descripción del Proyecto
Este repositorio contiene la implementación del modelo físico de base de datos relacional para la **Red Social Estudiantil Pascualina**, desarrollada en **PostgreSQL / pgAdmin 4**. El sistema está compuesto por **18 tablas lógicas** normalizadas hasta la Tercera Forma Normal (3FN), garantizando la integridad referencial y respondiendo a los requerimientos del entorno académico.

---

## Estructura del Repositorio
* `script_schema_pascualina.sql`: Código DDL con la creación de tablas, claves primarias, claves foráneas y restricciones CHECK.
* `diagrama_erd_pascualina.png`: Diagrama Entidad-Relación físico generado en pgAdmin 4.
* `Informe_Tecnico_Pascualina.pdf`: Documento técnico justificando el SGBD, la normalización y las reglas de integridad.
* `README.md`: Documentación principal de la entrega.
