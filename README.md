## Descripción del Proyecto
Este repositorio contiene el desarrollo e implementación del **sistema de consultas (DML) y vistas (Views)** para la base de datos de la **Red Social Estudiantil Pascualina**. El sistema está diseñado para responder a las preguntas de negocio y resolver la necesidad de comunicación informal, creación de grupos de estudio, seguimiento entre compañeros, mentorías y programación de eventos académicos dentro de la comunidad universitaria.

Para responder a los retos de la tercera unidad y a los criterios de la actividad, se incluyen tanto los borradores individuales con sus reglas de nomenclatura (`ALIAS`) como el script final detallado y comentado de creación de vistas y consultas SQL.
