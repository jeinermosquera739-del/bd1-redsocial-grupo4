##  Descripción del Proyecto
Este repositorio contiene la solución completa para el diseño, adaptación e implementación del modelo de base de datos físico de la **Red Social Estudiantil Pascualina**. El sistema está diseñado para resolver la necesidad de comunicación informal, creación de grupos de estudio, seguimiento entre compañeros, mentorías y programación de eventos académicos dentro de la comunidad universitaria.

Para responder a los retos del entorno académico y los criterios de la tarea, la arquitectura adopta un **modelo híbrido (SQL + NoSQL/JSON)** implementado en tres Sistemas de Gestión de Bases de Datos (SGBD): **PostgreSQL**, **MySQL 8.0+** y **SQL Server**.
